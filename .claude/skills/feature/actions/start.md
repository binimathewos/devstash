# Start Action

1. Read current-feature.md - verify Goals are populated
2. If empty, error: "Run /feature load first"
3. Set Status to "In Progress"
4. Create and checkout the feature branch (derive name from H1 heading)
5. Create a todos list (TodoWrite) from the Goals — one item per goal
6. Implement the goals one by one, updating the todos list as you progress (mark each done, keep one in_progress at a time)
